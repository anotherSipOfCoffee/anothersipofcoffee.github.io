Parametric System · 2026

Modular Housing Configurator

Not launched — in development

A kit-of-parts approach to modular housing: a fixed catalogue of components — panels, columns, beams, connectors — combined through a fixed grid to produce many different layouts. The goal is an online configurator where a user sets a footprint, module count, and program, and the system generates a layout, a 3D model, a drawing set, and a bill of quantities automatically, similar in spirit to Ludwig's configurator for kit timber structures.

The logic — module grid, component library, and generation rules — is being developed in Grasshopper, with the long-term goal of a standalone web configurator that doesn't require the visitor to have Rhino installed.

  • Concept2026

    Module system & rules

    Defining the base module grid, the component catalogue, and the rules that keep every generated layout structurally and dimensionally valid.

  • In progress2026

    Grasshopper definition

    Building the parametric definition that turns a set of inputs (footprint, module count, program) into a full layout and outputs a drawing set and parts list.

  • Planned

    Web configurator

    Porting the logic to a browser-based interface so a visitor can configure and preview a layout without any other software.

Not live yet — if you'd like to hear when it launches, or want to talk about the system, get in touch.
