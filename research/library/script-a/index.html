Café island from two axes

One continuous counter around a central workspace, with rounded perimeter corners and an entrance through the body, worktop and plinth.

Download script + launcher (.zip) ↓Read engine source ↗

Expected result

In 3D: a plain counter body, a separate worktop and a recessed plinth. In plan: the counter outline, central opening and entrance. No appliances, chairs or overhead structure are generated.

Inputs and controls

Reference two straight, horizontal axes that intersect inside their lengths. Perpendicular axes produce a rectangular footprint; angled axes produce a parallelogram. Each axis sets a footprint dimension, rather than a separate counter run.

ControlPurpose
Scale1 / Scale2Scale each axis independently around the intersection.
ModuleStepRound total axis lengths to an increment; 0 gives continuous scaling.
Depth / HeightCounter depth and finished height, independent of axis scaling.
CornerRadiusRound the perimeter corners.
EntranceWidth / Side / ShiftSet the opening size and location.
TopThickness / OverhangControl the worktop.
PlinthHeight / PlinthInsetControl the recessed base.
MinWorkspace / BaseOffsetMinimum modelling clearance and elevation offset.

All dimensional controls use millimetres, regardless of Rhino document units.

Run in Rhino

  1. Extract the ZIP and keep both Python files together.
  2. Run RunPythonScript and select Launch_Cafe_Island.py.
  3. Select your two axes, or press Enter at the first prompt for an example.
  4. The launcher opens a wired Grasshopper definition. Save it with File → Save As.

Uses legacy GhPython in Rhino 7/8. It configures the curve type hints and sliders automatically.

Send to Archicad

Geometry is local to the axes intersection; Preview and Plan are positioned in Rhino world coordinates. Angle 0 adds no extra rotation. Enable synchronisation when ready, and check the project origin, elevation and orientation after transfer.

The connector creates the library part from the generated geometry. Plan is a Rhino reference output, not a separate custom GDL symbol. Check the generated object's floor-plan representation and story visibility in Archicad. These files are Python scripts for Live Connection, not a standalone .gsm download.

Version notes

This is the existing café-island script, preserved unchanged. Syntax and independent 2D layout checks passed. Its transfer to Archicad has been demonstrated in use; a preview/placement mismatch was reported and has not been diagnosed. Do not assume Angle 0 fixes that mismatch.
